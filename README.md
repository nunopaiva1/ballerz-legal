# BallerZ legal pages

Privacy Policy and Terms of Use for BallerZ, published with GitHub Pages:

- https://nunopaiva1.github.io/ballerz-legal/privacy.html
- https://nunopaiva1.github.io/ballerz-legal/terms.html

To change them: edit `src/privacy.md` or `src/terms.md`, set `UPDATED` in `src/build.py`, run `python src/build.py` (needs `pip install markdown`), then commit and push.
